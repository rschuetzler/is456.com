## What students do

- Add a feature from a written spec to a provided small Express/Postgres app.
- Write the acceptance tests before asking the agent to build.
- Review the diff and find the defect.
- Open a pull request; a teammate reviews it.
- Check-off 1: explain a section and change it, with a TA and no AI.

## What they should notice

- Tests written first catch things a read-through misses.
- Reviewing a diff is a separate skill from writing code.
- "It runs" and "it is right" are different claims.

## To build

Starter app, feature spec, and a planted defect. Don't describe the defect in this public repo.
