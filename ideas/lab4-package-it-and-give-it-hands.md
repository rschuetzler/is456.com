## What students do

- List five tasks you repeat. Turn one into a skill with a script inside. Test on three inputs and revise.
- Wrap Lab 0's `tools.py` as an MCP server and query the Summit Ridge database from Codex.
- Run one task non-interactively from a script.
- Write a one-paragraph Capstone 1 plan.

## What they should notice

- The same Python tool works in a hand-written loop, in LangChain and behind MCP.
- A skill is mostly clear writing.
- An unattended run needs tighter permissions than an attended one.
