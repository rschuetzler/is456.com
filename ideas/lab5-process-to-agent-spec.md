## What students do

- Annotate the procure-to-pay model task by task: rule or judgment, volume, cost of error, reversibility.
- Pick one task for the team's agent.
- Write the agent design: tools, approval gates, escalation rules, what it must never do.
- Write 15 eval scenarios from the model's paths and exceptions, as data files.
- Assign leads for Labs 6–9.

## What they should notice

- Most tasks should not be handed to an agent.
- The exceptions produce most of the eval scenarios.
- The design can be argued about before any code exists.
